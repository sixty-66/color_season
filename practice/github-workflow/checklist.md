# Pull request safety checklist

Before merging a change:

- [ ] Confirm the source repository belongs to the intended owner.
- [ ] Confirm the target branch is the intended isolated practice branch.
- [ ] Read the changed-file list and verify no unrelated code changed.
- [ ] Check that no private keys, passwords, tokens, or personal data were committed.
- [ ] Avoid requesting review or notifications from unrelated maintainers.
- [ ] Merge only after confirming that the change is documentation-only or appropriately tested.

This checklist is a standalone exercise on a non-default branch.
