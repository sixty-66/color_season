# GitHub pull request practice

This guide lives on the isolated `practice/achievements-2026-11-13` branch, separate from the project's default `main` branch. It is documentation-only and does not change application code.

## Safe contribution workflow

1. Create a topic branch from the branch you intend to update.
2. Make one focused change, with a descriptive commit message.
3. Open a pull request against the intended branch and inspect the changed files.
4. Merge after validating the scope of the change.
5. Keep experiments away from the production branch.

This is a personal workflow exercise, not a change request for external contributors.
